# PromptBuilder 组件设计

日期：2026-09-03
状态：已与用户确认

## 背景与目标

Prompt 文章页（如 `www/content/2.prompts/1.xxd-panel-001.md`）底部目前只有「原始提示词」代码块。原始仓库的 skill 里除原始提示词外还包含「运行适配器」（公共交付前言 + 四选一输出模式块 + 三选一文字模式块），文本统一记录在 `www/content/1.usage.md`。

目标：新建一个交互式 MDC 内容组件 `PromptBuilder.vue`，让用户在文章页选择画布比例、输出模式、文字模式后，实时拼装出适配器文本，并提供两个复制动作：

- 「复制追加部分」：只复制适配器拼装结果
- 「复制完整请求」：原始提示词全文 + 适配器拼装结果

## 已确认的决策

| 决策点 | 结论 |
|---|---|
| 文本存放 | 方案 A：适配器文本模板硬编码在组件内（`components/content/PromptBuilder.vue`），不抽 lib 数据文件 |
| 原始提示词获取 | slot 包裹：文章里的原始提示词代码块放进组件 slot，渲染样式不变，组件读取其文本 |
| 选项覆盖 | 全覆盖：比例（预设+自定义）、输出模式（含壁纸包子选项）、文字模式（含文案输入+语言）、其他要求 |
| 默认状态 | 预选 3:4 + TOP_BOTTOM + 模型生成 + 简体中文，**始终拼装**完整追加文本，按钮永远可用 |
| 复制 | 两个按钮：复制追加部分 / 复制完整请求 |

## 组件用法

每篇 Prompt 文章中，把原来的裸代码块改为：

```mdc
::prompt-builder
```text
（原始提示词全文，逐字不动）
```
::
```

## 卡片结构（自上而下）

1. **说明行**：一句话说明选项已按文档默认值预选，改动后复制即可
2. **原始提示词**：slot 渲染，样式与普通代码块一致（走 ProseCode）
3. **① 最终画布**：比例药丸单选，预设 12 个：`1:1, 3:4, 4:3, 4:5, 5:4, 2:3, 3:2, 9:16, 16:9, 21:9, 5:7, 7:5`；外加「自定义」，选中后出现输入框，支持 `16:10` 或 `1920x1080` 两种写法
4. **② 输出模式**（四选一）：TOP_BOTTOM 上下分栏 / LEFT_RIGHT 左右分栏 / DESIGN_ONLY 纯设计稿 / WALLPAPER_PACK 壁纸包；选壁纸包展开子选项——设备四选一（PHONE/IPAD/DESKTOP/WATCH）+ 壁纸关系二选一（INDEPENDENT/LINKED）
5. **③ 文字模式**（三选一）：模型生成 / 自定义文案 / 不要文字；模型生成与自定义文案显示语言下拉（简体中文 / 繁體中文 / English / 日本語，默认简体中文）；选自定义文案额外显示文字输入框（对应 `TEXT: 「…」`）
6. **④ 其他要求**（可选 textarea）：对应拼装公式最后一行「用户明确提出的其他准确要求」，留空不追加
7. **预览**：常显代码块，随选项实时更新，展示拼装出的追加文本
8. **复制按钮 ×2**：「复制追加部分」「复制完整请求」，复用 `CodeCopy.vue` 的复制 + toast 模式

视觉风格对齐 `PromptSource.vue`：`not-prose` + `rounded-lg border` 卡片，颜色用主题 token。

## 拼装规则

文本严格取自 `www/content/1.usage.md`（逐字）：

```
追加部分 = 公共交付前言（填入画布值）
         + 输出模式块（壁纸包时填入设备/关系）
         + 文字模式块（填入语言/文案）
         + 其他要求（若有，逐字放最后）

完整请求 = slot 原始提示词全文 + "\n\n" + 追加部分
```

- 默认组合（3:4 + TOP_BOTTOM + 模型生成）也完整拼装前言 + 模式块 + 文字模式块，不做"默认免追加"的特判
- 模板文本中的变量：`<比例和／或准确 WIDTHxHEIGHT>`、`<设备>`、`<壁纸关系>`、`<用户确认的语言或地区>`、`<用户准确文字>`

## 边界情况

- 自定义画布输入为空：预览中该行显示 `<比例>` 占位并给出提示，复制按钮不禁用（信任用户）
- 从壁纸包切走再切回：设备/关系子选项状态保留
- 预览初始在 SSR 中拼好，无水合闪烁
- slot 文本读取：组件挂载后从渲染容器读取 textContent；SSR 期间「复制完整请求」按钮不可用没关系（复制本身是客户端行为）

## 验证方式

- `pnpm dev` 访问 `/prompts/xxd-panel-001`，确认卡片渲染、原始提示词样式不变
- 切换各选项，确认预览文本实时正确变化（对照 usage.md 文本）
- 点击两个复制按钮，粘贴验证剪贴板内容
- `pnpm lint` 通过
