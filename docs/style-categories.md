## 混合风格如何选择

先判断作品最不可替代的表现方式。明确的媒材或成像方式通常优先于构图：纸雕微缩景观归纸艺；羊毛毡绘本归材质手作；东方专色木刻归版画。以超现实空间关系为核心的 008 归观念类，以实际等距模型为核心的 028 归微缩类。

“留白、纸感、旅行、海报、复古、上下分栏”在大量提示词中共有，不单独决定分类。忽略“避免、不要、不是”等否定要求；上半部分的原始摄影保留要求不能把每篇都归进摄影拼贴。

文章保留上游原名，并按原始提示词逐篇确定主分类。2026-10-01 同步上游后，178「手账墨记」归稚趣手绘与绘本；221「新中式专色版画留白」和 223「复古雕版微型图集」归版画，222「建筑化字体图形装置」归字体图形。左侧二级目录显示编号和标题，帮助辨认文章。

## 每次新增文章

1. 按现有收录流程写好文章，在项目根执行 `pnpm categories xxd-panel-224`（替换为实际编号）。
2. 脚本根据正文的正向风格要求加权匹配，自动写入缺失分类。已有分类保留；自动规则不调用外部模型，也不需要密钥。
3. 若脚本提示证据不足或类别接近，收录助手阅读全文后选择最合适的一类，直接写入 `styleCategory`。复核自动结果也是收录工作的一部分，不需要再让用户做分类。
4. 执行 `pnpm categories xxd-panel-224 --check`，再继续缩略图与页面验证。

`pnpm dev`、`pnpm build`、`pnpm generate` 启动前也会自动补齐缺失分类；开发服务已运行时，新文章通过上述收录命令完成归类。`pnpm categories:check` 为只读全站检查，CI 会拦截缺失或无效分类。`pnpm test:categories` 验证分类、目录及脚本行为。

目录从文章元数据动态生成，不移动文件、不改变 `/prompts/xxd-panel-NNN` 链接。分类名称跳到类内编号最小的文章；箭头单独控制展开；直接打开或切换到文章会展开所属分类。遗漏分类的本地草稿在“待分类”中仍可访问，不能通过收录检查。
